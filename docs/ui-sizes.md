# 화면 UI 크기

> **역할**: 화면에 보이는 **글자·여백·컨트롤 크기**의 코드 정본. 색·카피는 여기 없음.  
> **단위**: React Native dp(밀도 독립 픽셀). 별도 표기가 없으면 dp.  
> **정본**: `src/constants/theme.ts` · `src/components/themed-text.tsx` · `src/components/ui/*`. 화면 파일이 `fontSize`를 직접 적으면 그 값이 이긴다.  
> **상태**: 2026-08-26 코드 기준. 라이트 전용. Android 우선.  
> **표기**: `근거`(파일) · `주의` · `미검증`.

관련: [`training-stats-recommendation.md`](./training-stats-recommendation.md)(통계 화면 구성).

## 0. 한 줄

본문 글자는 **14 미만 금지**. 손가락 타깃은 **44~48**. 본문 폭은 폰에서 풀폭, 태블릿만 **560**에서 잘린다.

화면 좌우 패딩은 거의 `four`(24). 카드 안은 `three`(16).

### 모서리 `Radius`

| 이름 | dp | 쓰는 곳 |
|------|----|---------|
| `small` | 12 | 아이콘 타일·작은 버튼 |
| `medium` | 14 | `ActionButton` |
| `large` | 20 | 선택지 타일. 카드는 `large - 2` = **18** |

| `pill` | 999 | 알약·칩·진행바 |

### 본문 최대 폭

`MaxContentWidth` = **560**. 폰(대략 320~411)에서는 안 걸린다. 태블릿에서만 가운데 정렬.

`근거`: 실기기 901dp에서 800은 한 글자 칸이 과하게 넓어 560으로 둠.

### 글꼴 이름

Android: 본문 `normal`, 수치 `monospace`. 웹 CSS 변수는 `src/global.css`(이 앱 실기기는 해당 없음).

### 안 쓰는 토큰

`BottomTabInset`(iOS 50 / Android 80) — **참조 0**. 하단 탭 높이는 NativeTabs(OS)가 잡는다.

## 2. 글자 (`ThemedText`)

`근거`: `src/components/themed-text.tsx`.

캡션 주석: **고령·난청 가독성 → 화면에서 11~13으로 줄이지 말 것.** 하한은 14.

| `type` | 크기 / 행간 | 굵기 | 용도 |
|--------|-------------|------|------|
| `small` · `smallBold` · `caption` · `mono` | 14 / 20 | 500 / 700 / 500 / 600 | 본문·안내·버튼 라벨·배지 숫자 |
| `default` | 16 / 24 | 500 | 타입 생략 시 |
| `link` · `linkPrimary` | 14 / 30 | — | 링크 |
| `code` | 14 | Android 700 | 코드 |
| `screenTitle` | 23 / 30 | 700, 자간 -0.2 | 목록·연습 화면 제목 |
| `heading` | 26 / 34 | 700, 자간 -0.3 | 히어로 제목(음고·떨림·다른 음) |
| `metric` | 24 / 30 모노 | 600 | 통계 큰 숫자 |
| `subtitle` | 32 / 44 | 600 | (거의 안 씀) |
| `title` | 48 / 52 | 600 | (거의 안 씀) |

`mono`는 크기가 `small`과 같다. 더 줄이지 않는다.

### 화면에서 타입을 덮어쓰는 값

토큰이 아니라 화면 `StyleSheet`다. 자주 나오는 것만.

| 크기 / 행간 | 어디서 |
|-------------|--------|
| 15 / 22 | 연습 선택 카드 제목, 진행 중 헤드라인(음고·떨림) |
| 16 / 22 | 요약 헤드라인, 재생 중 상태 |
| 18 / 24 | 높낮이 보기 칸 라벨 |
| 20 / 28 | 링6·한 글자·두 글자 요약 한 줄 |
| 26 / 32~34 | 빙고 글자, 두 글자 보기 |
| 28 / 36 | 한 글자 보기 |
| 34 | 통계 최근 값(`SessionTrendPanel`) |
| 36 / 44 | 다른 음 찾기 보기 숫자 |

### 14 미만 (예외)

| 값 | 어디 | 왜 |
|----|------|----|
| SVG `fontSize={9}` | 추이 그래프 y축(0·50·100 등) | `SvgText`. `ThemedText` 하한이 아님 |
| idle `heroPrompt` 12.5 | 음고·떨림·다른 음 시작 안내 | × `TEXT_SCALE` 1.2 → **15** |
| 듣기 준비 본문 12 | `ListeningCheckScreen` | × 1.2 → **14.4** |
| 토글 힌트 기준 10.5 | `SessionModeToggle` | `textScale === 1`이면 스타일이 **14/20**으로 덮음. 배율 켤 때만 10.5×배율 |

OS 글자 배율(`allowFontScaling`)은 끄지 않았다. 시스템 설정이 위 숫자에 또 곱해진다. `미검증`: 실기기 font scale.

### `TEXT_SCALE = 1.2`

시작 안내(idle)와 듣기 준비에서만 글자를 키운다. 연습 중 보기 칸에는 안 곱한다.

적용: `ListeningCheckScreen`, `PitchCompareScreen`, `FreqSessionScreen`, `AmSessionScreen`(idle). `ActionButton`·`Pill`·`SessionModeToggle`의 `textScale`.

예: 버튼 라벨 14×1.2 = **16.8**, 행간 20×1.2 = **24**.

## 7. 단정 금지

- `주의`: NativeTabs 라벨·아이콘·탭바 높이는 OS. 여기 숫자로 맞출 수 없음.
- `주의`: 시스템 글자 배율이 켜져 있으면 표의 dp보다 커진다.
- `미검증`: 통계 칩 줄이 좁은 화면에서 어떻게 접히는지.
- `미검증`: `sentClosed` 화면 크기는 파일 기준. 하단 탭에 문장 듣기가 없음.
