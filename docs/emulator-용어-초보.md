# 에뮬 개발 용어 — 초보 비유 사전

> **목적**: [`emulator-usb-전환-초보.md`](./emulator-usb-전환-초보.md)에 나온 말을 **한 줄 뜻 + 비유**로만 정리.
> **비유는 감 잡기용**이지 기술 명세가 아니다. 명령 순서는 위 가이드를 본다.
> **근거**: 2026-08-28 USB→에뮬 세션에서 실제로 나온 단어.

---

## 0. 큰 비유 하나

PC는 **본사 건물**, 에뮬은 건물 안 **연습용 매장**, USB 폰은 거리의 **실제 매장**이다.
앱(APK)은 매장에 두는 **계산대 상자**, Metro는 본사가 매일 보내는 **오늘 메뉴판(JS)** 방송이다.

세 층이 따로 돈다. 매장(에뮬)이 꺼져 있으면 상자를 둘 곳이 없고,
상자가 없으면 메뉴판을 걸어 둘 못이 없고, 방송(Metro)이 없으면 상자는 있는데 메뉴가 어제 것이다.

## 1. 한눈에 용어 정리

| 말 | 한 줄 | 비유 |
|----|-------|------|
| **에뮬레이터** | PC 안에서 돌아가는 가상 안드로이드 폰 | 본사 건물 안 **연습용 매장**. 진짜 폰이 아님 |
| **AVD** / **Pixel_7** | 에뮬의 **기종 설정** 이름 | 매장 도면 이름. `-list-avds`로 목록을 봄 |
| **emulator-5554** | adb가 그 에뮬에 붙인 **번호표** | 매장 내선번호. 5554는 흔히 첫 에뮬 |
| **실기기** / **SC_01M** | 손안의 진짜 폰 | 거리의 **실제 매장**. 연습 매장과 재고가 다름 |
| **APK** | 안드로이드에 설치되는 앱 파일 | 매장에 두는 **계산대 상자** |
| **dev client** | 우리 전용 개발용 APK | 본사만 쓰는 상자. 편의점 공용 상자(Expo Go)와 다름 |
| **Expo Go** | 공용 개발 앱. **이 프로젝트는 불가** | 남의 공용 상자. 우리 기계(오디오·Skia)가 안 들어감 |
| **패키지** `com.harmonitune.app` | 앱의 주민등록번호 | 상자 바코드. 아이콘 이름과 별개 |
| **Metro** | JS/TSX를 기기에 실시간으로 보내는 서버 | **오늘 메뉴판 방송**. 포트 보통 **8081** |
| **`npm start`** | Metro만 켬 | 방송국만 킴. 상자가 이미 있어야 함 |
| **`npm run android`** | APK를 지금 잡힌 기기에 만들어 설치 | 상자 **공장 돌리고 매장에 배달** |
| **Node** | JS를 실행하는 엔진. Metro가 그 위에서 돔 | 방송국 기계. 탭이 `node`면 방송 중 |
| **Java** | Gradle이 돌아가는 엔진 | 상자 공장의 **전원**. 탭이 `java`면 공장 가동 중 |
| **Gradle** | 안드로이드 빌드 총괄 | 공장 **현장 감독**. 순서·재료를 지휘 |
| **CMake** | C++(네이티브)를 기기 CPU용으로 컴파일 | 상자 안 **모터 가공**. 제일 오래 걸림 |
| **x86_64** | PC/에뮬 CPU 종류 | 연습 매장 전기 규격. 폰(ARM)과 다를 수 있음 |
| **`.so`** | 네이티브 라이브러리 파일 | 모터 부품. 하드링크 실패면 **복사**로 대체 |
| **adb** | PC가 기기를 조종하는 도구 | 본사→매장 **리모컨** |
| **`adb devices`** | 지금 잡힌 기기 목록 | 리모컨에 **매장이 잡혔나**. 상자 유무가 아님 |
| **offline** / **device** | adb 연결 상태 | offline=내선은 있는데 아직 통화 불가 |
| **daemon / 5037** | PC에서 adb가 상시 대기하는 문 | 리모컨 중계실. 처음엔 문이 닫혀 있을 수 있음 |
| **SDK** | 안드로이드 개발 도구 모음 | 본사 공구함. `adb`·`emulator`가 들어 있음 |
| **PATH** | 터미널이 명령을 **어디서 찾나** 목록 | 공구함 **찾아보는 선반 목록**. 없으면 `command not found` |
| **`$env:LOCALAPPDATA`** | Windows에서 「이 사용자 AppData」 경로 | 내 책상 서랍 주소. PowerShell 표기 |
| **`$LOCALAPPDATA`** | 위와 같은 곳. Git Bash 표기 | 같은 서랍, **다른 말** |
| **`&`** (PowerShell) | 「이 경로 파일을 **실행**하라」 | 주소만 읽지 말고 **그 공구를 집어라** |
| **PowerShell / Git Bash** | 서로 다른 터미널 언어 | 같은 건물, **안내 방송 언어가 다름** |
| **포트 8081** | Metro가 메뉴판을 내보내는 문 | 방송 채널 |
| **127.0.0.1** | 「나 자신」 주소 | 매장 안 내부 전화 |
| **10.0.2.2** | 에뮬이 보는 **PC(호스트)** | 연습 매장에서 본사로 가는 **전용 복도** |
| **`adb reverse`** | 기기의 8081을 PC Metro로 넘김 | 내부 전화를 본사 방송에 **연결** |
| **USB 디버깅** | 폰이 USB로 adb를 허용 | 실제 매장이 본사 리모컨을 **허가** |

## 2. 이야기처럼 이어 읽기

「에뮬레이터를 켠다」는 본사 건물 안에 **연습용 매장 문을 여는 것**이다.
Android Studio는 그 문을 눌러 주는 버튼일 뿐이고, 실제로는 `emulator.exe`가 연다.
이미 화면에 매장이 보이면 문을 또 열 필요 없다.

매장이 열리면 adb(리모컨)가 번호표를 붙인다. 그게 **emulator-5554**다.
`adb devices`는 「리모컨에 매장이 잡혔나」만 본다. **상자가 있나**가 아니다.
상자는 앱 서랍의 「청능 애플리케이션」 아이콘으로 본다.

상자가 없으면 Gradle(현장 감독)이 Java(전원)로 공장을 돌린다.
그중 CMake가 모터(C++)를 에뮬 전기 규격(x86_64)에 맞게 깎는다.
그래서 99%에서 몇 분 멈춘 것처럼 보인다. **아직 배달 중**이다.

배달이 끝나면 같은 터미널이 공장(Java)에서 방송국(Node/Metro)으로 바뀌는 경우가 많다.
그때부터는 오늘 메뉴판(JS)이 상자에 붙는다. `npm start`만 한 것과 같은 층이다.

USB 폰은 **다른 건물(실제 매장)** 이다. 거기 둔 상자는 연습 매장으로 안 옮겨진다.
그래서 에뮬을 처음 쓰면 공장을 한 번은 돌려야 한다.

## 3. 화면에 뜨면

| 보인 것 | 쉬운 말 |
|---------|---------|
| `adb: command not found` | 이 터미널 선반 목록(PATH)에 리모컨이 없음. 전체 경로로 집거나 셸을 맞출 것 |
| `식 또는 문에서 예기치 않은 'shell'` | PowerShell인데 Git Bash처럼 침. 앞에 `&`가 없음 |
| Gradle 99% `buildCMakeDebug[x86_64]` | 모터 가공 중. 기다림 |
| `Doing a slower copy instead` | 부품을 바로 못 잇고 **복사**. 실패 아님 |
| 탭 이름 `java` → `node` | 공장 끝, 방송 시작. 에러 없으면 정상 |
| `Unable to connect ... 5037` | 리모컨 중계실이 아직 안 열림. 곧 열리는 경우가 많음 |
| `device offline` | 매장 문은 열렸는데 내선이 아직 안 받음 |
| Development servers | 상자는 있는데 **메뉴판 방송 주소**를 모름 |
| `http://10.0.2.2:8081` | 연습 매장 → 본사 방송 채널 |

## 4. 단정 금지

| 표시 | 내용 |
|------|------|
| **관례** | 첫 에뮬 번호가 5554인 것, CMake가 제일 긴 것, `0x502`를 화면 정상이면 무시하는 것 |
| **미검증** | 모든 PC에서 `%LOCALAPPDATA%\Android\Sdk` 경로가 같은지 |
| **주의** | 비유(매장·리모컨)를 코드 구조와 1:1로 맞추면 어긋남. 감만 잡을 것 |
