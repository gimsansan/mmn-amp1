# 훈련 통계 — 수집·표시 추천 (이 앱용)

> **역할**: 탭별 연습 기록을 **어떻게 넣고, 어떻게 꺼내 보여줄지**의 추천. 웰니스·훈련. 진단·점수 UI 아님.  
> **상태**: 2026-08-20 대화 합의 반영. **코드 미적용.** 구현 시 이 자리를 고친다(갱신형).  
> **표기**: `근거`(파일) · `관례` · `추정` · `미검증` · `주의`. 단정 금지는 §8.  
> 관련: [`amp-mdt-training-design.md`](./amp-mdt-training-design.md)(왜 이 훈련인가) · 저장 구현은 `src/training/*Store.ts`.

---

## 0. 한 줄

밥상(봉투)은 범용으로 깔고, **나온 반찬만 담고, 그 탭 행만, 담긴 것만 내놓는다.**

엑셀로 보면: 공통 열 + 행마다 있는 칸만 채움 + `kind`로 필터 + 빈 칸은 시트에 안 그림.

---

## 1. 이 앱에 맞추는 이유

하단 탭 4개, 과제는 그보다 많다.

| 탭 | 과제 (`kind`) | 지금 저장 (`근거`) |
|----|---------------|-------------------|
| 링 6 | `ling6` | `training.ling6Daily.v1` — **하루 1건** 덮어쓰기 |
| 소리 높낮이 | `pitch2` · `freq` | `training.sessionHistory.v1` — 세션 append |
| 단어 듣기 | `wrs1` · `wrs2` | `wrsSessions.v1` / `twoCharSessions.v1` — 완료 세션만 |
| 떨림 | `am` | **음고와 같은 상자** `sessionHistory.v1` |
| (한 글자 안) 빙고 | 없음 | 저장 안 함. 통계도 없음 |

`관례`: 소비자 훈련 앱은 **끝난 연습 1회 = 이벤트 1건**(세션 요약). 문항마다·탭할 때마다 남기는 건 기본이 아님.

이 앱은 로컬 AsyncStorage, 중사양, 측정 화면은 정적. 통계도 **가벼운 요약**이 맞다.

---

## 2. 법칙 둘 (화면이 수월해지는 핵심)

1. **그 탭 행만** — 꺼낼 때 `kind`(또는 탭이 맡은 kind 목록)만.  
2. **없는 칸은 내놓지 않음** — 넣지 않은 항목은 그 화면에서 그리지 않음. 공란 접시를 만들지 않음.

같은 상자를 써도 된다. 문제는 상자가 아니라 **꺼내는 화면이 상자 전체를 펼치는 것**.

---

## 3. 넣는 쪽 — 범용 봉투

겉면은 모든 과제 공통. 속(`payload`)만 과제별. 못 넣는 항목은 **패스**(키를 안 넣거나 생략).

```ts
{
  id, schemaVersion,
  kind: 'ling6' | 'pitch2' | 'freq' | 'am' | 'wrs1' | 'wrs2',
  occurredAt,                 // ISO
  grain: 'session' | 'day',   // 링 6만 day
  includeInTrend: boolean,    // 귀풀기 false. 링6·단어는 보통 true
  payload: { ... }            // 있는 숫자만
}
```

| kind | payload에 넣는 것 (지금 요약으로 충분) | 안 넣는 것 |
|------|------------------------------------------|------------|
| `ling6` | 맞힌 개수 0~6, 음소별 참/거짓 | 세션 횟수로 가로축을 늘리지 않음(날짜) |
| `pitch2` · `freq` | 시행·정답·반전, 대표 Δ(cent) | 대표값 없으면 추이 점 제외 |
| `am` | 위와 같되 대표값은 떨림 깊이 | cent 그래프용 값 |
| `wrs1` | 25문항 맞힌 수·% | 두 글자 표, 문항 전체 로그 |
| `wrs2` | 12문항 맞힌 수·% | 한 글자 200개 목록 |

**저장 키를 지금 당장 하나로 합치지 말 것.** (`주의`: 기존 4키 마이그레이션)  
읽는 API만 봉투로 **투영**하면 된다. 음고·떨림은 **지금 상자 유지**가 맞다.

문항 전체·틀린 단어 목록은 **2단계**. 필요할 때 payload에만 붙인다.

---

## 4. 꺼내는 쪽 — 탭이 고른다

```
떨림 탭     → kind=am              → 떨림 선·목록만
소리 높낮이 → pitch2 또는 freq     → 음고 선·목록만
링 6        → kind=ling6           → 개수·음소 격자(실기록만)
한 글자     → kind=wrs1            → 맞힌 %
두 글자     → kind=wrs2            → 맞힌 %
```

**음고 칩(토글)**  
높낮이 비교 / 다른 음 찾기는 단위가 같아서, 선을 겹치지 않고 **하나만** 보게 한 목적.  
그 토글은 **소리 높낮이 통계에서만**. 떨림 화면에 칩·음고 선을 두지 않음.

**떨림**에는 음고를 고르는 칸이 없음 → 떨림에서 열면 떨림만.

화면 뼈대는 탭마다 같게:

1. 이번 결과 한 줄  
2. 선 그래프 — **실기록 점 2개 이상일 때만**  
3. 최근 몇 회  
4. 이 탭(이 kind) 기록만 지우기  

입구도 같게: 헤더 차트 버튼 → 위 템플릿. 시작 화면에 차트·목록을 쌓지 않는 쪽을 권함.

## 5. 하지 말 것 (지금 어긋난 점과 대응)

| 하지 말 것 | 지금 (`근거`) | 추천 |
|------------|----------------|------|
| 떨림에서 음고까지 펼치기 | `SessionHistoryScreen`은 `clearTracks`만 삭제용. 목록·그래프는 3트랙 전부 | `kind` 필터 |
| 여러 과제를 한 정답률로 합치기 | 같은 화면 상단 「평균 정답률」이 pitch2+freq+am 문항을 합침 | 탭 지표 1개 |
| 점 부족한데 가짜 점 | `Ling6ProgressPanel` `ensureTwoDays` — 난수 미리보기 날짜 | 선 숨김. 「내일 또 하면 선이 생겨요」 |
| 없는 지표를 공란으로 강요 | 과제마다 카드 밀도가 다름 | 넣은 칸만 출력 |
| 세션 미완료를 통계에 | 단어 25/12 미완료·링6 6음 미완은 저장 안 함 | 유지 |
| 빙고를 억지 통계 | 맞히기 기록 없음 | 빈 접시. 통계 화면 없음 |

차트 읽는 법도 탭 카드에 한 줄: 음고·떨림은 **낮을수록**, 단어·링6은 **높을수록**. 위젯을 억지로 한 방향으로 맞추지 말 것.

## 6. 구현 순서 (코드 아직 없음)

1. `SessionHistoryScreen`에 **볼 kind**를 넘긴다. 떨림 → `am`만. 음고 → `pitch2`·`freq`(+칩은 이 화면만).  
2. 링6 가짜 점 제거.  
3. 표시 템플릿을 단어·링6과 맞출지는 1 다음에. 저장 키 통합은 더 뒤.

`추정`: JS만이면 **리빌드 불필요.**

## 8. 단정 금지

- `주의`: 맞힌 %·반전 평균 ≠ 청력·인지도 향상. 병원 검사 아님.
- `주의`: 봉투를 공통 열로 펼쳐도, 없는 값을 0으로 채우면 안 됨(가짜 기록).
- `추정`: 서버 이관 시 이 봉투가 이벤트 스키마로 간다. 아직 백엔드 없음.
- `미검증`: 필터·가짜 점 제거 후 실기기 UX.
- `관례`: 세션 1건 수집이 흔함. 이 앱에서 A/B로 검증한 것은 아님.
