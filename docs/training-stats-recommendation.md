# 훈련 통계 — 수집·표시 추천 (이 앱용)

> **역할**: 탭별 연습 기록을 **어떻게 넣고, 어떻게 꺼내 보여줄지**의 추천. 웰니스·훈련. 진단·점수 UI 아님.  
> **상태**: 2026-08-20 §5 1·2 + 입구 + 음고·떨림 회차별 카드 제거 + 링6 격자 제거·약점 1줄 + 음고·떨림 추이 읽는 법 + 귀풀기 미저장 + 링6·단어 높을수록 + 한 글자·두 글자 표시 표. **2026-08-21 통합 통계 화면**(칩 6개 + 「다른 연습」 3줄) + 읽기 창구 `statsFeed`. 표시 뼈대 통일까지 적용. **저장 키 통합은 여전히 뒤.**  
> **표기**: `근거`(파일) · `관례` · `추정` · `미검증` · `주의`. 단정 금지는 §8.  
> 관련: [`amp-mdt-training-design.md`](./amp-mdt-training-design.md)(왜 이 훈련인가) · 저장 구현은 `src/training/*Store.ts`.

## 0. 한 줄

밥상(봉투)은 범용으로 깔고, **나온 반찬만 담고, 그 탭 행만, 담긴 것만 내놓는다.**

엑셀로 보면: 공통 열 + 행마다 있는 칸만 채움 + `kind`로 필터 + 빈 칸은 시트에 안 그림.

---

## 1. 이 앱에 맞추는 이유

하단 탭 4개, 과제는 그보다 많다.

| 탭 | 과제 (`kind`) | 지금 저장 (`근거`) |
|----|---------------|-------------------|
| 링 6 | `ling6` | `training.ling6Daily.v1` — **하루 1건** 덮어쓰기 |
| 소리 높낮이 | `pitch2` · `freq` | `training.sessionHistory.v1` — 세션 append |
| 단어 듣기 | `wrs1` · `wrs2` | `wrsSessions.v1` / `twoCharSessions.v1` — 완료 세션만 |
| 떨림 | `am` | **음고와 같은 상자** `sessionHistory.v1` |
| (한 글자 안) 빙고 | 없음 | 저장 안 함. 통계도 없음 |

`관례`: 소비자 훈련 앱은 **끝난 연습 1회 = 이벤트 1건**(세션 요약). 문항마다·탭할 때마다 남기는 건 기본이 아님.

이 앱은 로컬 AsyncStorage, 중사양, 측정 화면은 정적. 통계도 **가벼운 요약**이 맞다.

---

## 2. 법칙 둘 (화면이 수월해지는 핵심)

1. **그 탭 행만** — 꺼낼 때 `kind`(또는 탭이 맡은 kind 목록)만.  
2. **없는 칸은 내놓지 않음** — 넣지 않은 항목은 그 화면에서 그리지 않음. 공란 접시를 만들지 않음.

같은 상자를 써도 된다. 문제는 상자가 아니라 **꺼내는 화면이 상자 전체를 펼치는 것**.

---

## 3. 넣는 쪽 — 범용 봉투

겉면은 모든 과제 공통. 속(`payload`)만 과제별. 못 넣는 항목은 **패스**(키를 안 넣거나 생략).

```ts
{
  id, schemaVersion,
  kind: 'ling6' | 'pitch2' | 'freq' | 'am' | 'wrs1' | 'wrs2',
  occurredAt,                 // ISO
  grain: 'session' | 'day',   // 링 6만 day
  includeInTrend: boolean,    // 음고·떨림 귀풀기는 저장 안 함. 링6·단어는 보통 true
  payload: { ... }            // 있는 숫자만
}
```

| kind | payload에 넣는 것 (지금 요약으로 충분) | 안 넣는 것 |
|------|------------------------------------------|------------|
| `ling6` | 맞힌 개수 0~6, 음소별 참/거짓 | 세션 횟수로 가로축을 늘리지 않음(날짜) |
| `pitch2` · `freq` | 시행·정답·반전, 대표 Δ(cent) | 대표값 없으면 추이 점 제외 |
| `am` | 위와 같되 대표값은 떨림 깊이 | cent 그래프용 값 |
| `wrs1` | 25문항 맞힌 수·% | 두 글자 표, 문항 전체 로그 |
| `wrs2` | 12문항 맞힌 수·% | 한 글자 200개 목록 |

**저장 키를 지금 당장 하나로 합치지 말 것.** (`주의`: 기존 4키 마이그레이션)  
읽는 API만 봉투로 **투영**하면 된다 — `근거`: `src/training/statsFeed.ts`(2026-08-21). 저장소 4개는 그대로 두고 `loadStatsFeed()`가 한 번에 읽어 `kind`로만 꺼내 쓴다. 음고·떨림은 **지금 상자 유지**가 맞다.  
음고·떨림 **귀풀기는 넣지 않음**(이번 결과 카드만). 연습(측정)만 트랙별 50.

문항 전체·틀린 단어 목록은 **2단계**. 필요할 때 payload에만 붙인다.

## 4. 꺼내는 쪽 — 칩이 고른다 (2026-08-21 개정)

통계 화면은 **하나**(`StatsScreen`). 네 탭 어디서 헤더 차트 버튼을 눌러도 같은 화면이 뜨고,
**그 탭의 종목이 선택된 채로** 열린다. 다른 종목은 칩 하나로 건너뛴다.

```
링 6        → kind=ling6           → 약점 1줄(최근 7건) + 맞힌 개수 선(전체)
높낮이 비교 → kind=pitch2          → 음고 선만
다른 음 찾기→ kind=freq            → 음고 선만
한 글자     → kind=wrs1            → 맞힌 % 선(2회+) + 최근 8회
두 글자     → kind=wrs2            → 같은 패널, 목록은 맞힌/12
떨림        → kind=am              → 떨림 선만
```

**한 번에 하나만 그린다.** 칩 6개가 한 줄에 있어도 화면에 그려지는 건 고른 종목 하나뿐이다.
네 그래프를 세로로 쌓지 않는다(스크롤만 길고 단위가 달라 비교도 안 됨).

**음고 두 과제**(높낮이 비교 · 다른 음 찾기)는 단위가 같아 선을 겹치지 않고 하나씩 본다 —
이제 별도 토글이 아니라 위 칩 두 개다. **떨림을 고르면 떨림만**, 음고를 고르면 음고만.

**「다른 연습」 3줄** — 본문 아래. 지금 보고 있는 **탭을 뺀** 나머지 3탭의 근황을 한 줄씩.

```
다른 연습
링 6       어제 · 5/6 맞힘
단어 듣기   오늘 · 21/25 · 84%
떨림       기록 없음
```

- 그래프 없음. **최신 1건**만 읽어 「언제 · 결과」 한 줄.
- 한 탭에 종목이 둘이면(음고·단어) **더 최근에 한 쪽**을 보여 준다.
- 줄을 누르면 화면을 옮기지 않고 **위 칩만 바뀐다**(칩과 같은 동작의 두 표현).
- 목적은 「안 눌러도 보이게」. 칩만 있으면 다른 종목 상태를 눌러 봐야 안다.

화면 뼈대는 종목마다 같게 — 이제 껍데기가 **한 파일**이라 저절로 같다:

1. 종목 칩 한 줄  
2. 이번 결과 한 줄  
3. 선 그래프 — **실기록 점 2개 이상일 때만**  
4. 회차별 결과 카드 **없음**(음고·떨림 통계. 저장은 유지, 종목 지우기만)  
5. 「다른 연습」 3줄  
6. 이 종목(이 kind) 기록만 지우기  

입구도 같게: **적용** — 헤더 차트 버튼(`StatsEntryButton`) → 통계 화면. 시작·요약에 차트·목록 안 쌓음. 요약의 이번 결과 카드는 유지. 링6 idle 음소 미리보기(기록 0일)는 안내 칸이라 유지.

`주의`: 「다른 연습」은 **통계 화면 안**에만 있다. 시작 화면에 근황 줄을 얹지 않는다 — §5의 「시작 화면에 차트·목록 안 쌓음」은 그대로다. 홈 탭도 만들지 않았다(탭 4개 유지).

**링6 통계 두 축** (`근거`: 사용자 2026-08-20)

- 50일 P/F 격자: **화면에 안 그림**. 저장 50은 유지.
- 약점: 실기록 **7건부터**. 최근 7건 중 **4회 이상** 아쉬운 음소만 색+문구. 없으면 전부 회색·문구 없음. 격차·2위 비교 없음.
- 추이선: 저장 50·남은 점 전부. 자르기·스크롤 없음.
- 측정 화면 격자·저장 키 통합·음고/떨림 개편은 이 축과 섞지 않음.

**한 글자·두 글자 통계** (`근거`: `WrsProgressPanel` · 사용자 2026-08-20)

| 과제 | 화면 | 축·문구 | 규칙 |
|------|------|---------|------|
| 한 글자 | 맞힌 % 선 | x=시각, y=맞힌 % 0~100. 높을수록 위. 선 있을 때 「높을수록 더 많이 맞춤」. 「청력 검사가 아니에요」 | 완료 25문항만. **2회+** |
| 한 글자 | 최근 연습 | 최신 8회 · 맞힌/25 · % | 저장 50회 `wrsSessions.v1` |
| 두 글자 | 한 글자와 **같은** `WrsProgressPanel` | 축·문구 동일. 목록은 맞힌/12 · % | 완료 12문항만. 2회+. 저장 50회 `twoCharSessions.v1`. **키는 다름** |

축 반전 없음. 약점 막대 없음. 빙고는 이 표에 없음.

## 8. 단정 금지

- `주의`: 맞힌 %·반전 평균 ≠ 청력·인지도 향상. 병원 검사 아님. 링6 아쉬움 횟수도 청력 판정이 아님.
- `주의`: 봉투를 공통 열로 펼쳐도, 없는 값을 0으로 채우면 안 됨(가짜 기록).
- `추정`: 서버 이관 시 이 봉투가 이벤트 스키마로 간다. 아직 백엔드 없음.
- `미검증`: kind 필터·링6 선 숨김·헤더 통계 입구·약점 1줄·음고 추이 읽는 법·귀풀기 미저장·링6·단어 높을수록·한 글자·두 글자 표시 표 실기기 UX.
- `미검증`: 통합 통계 화면(칩 6·「다른 연습」 3줄) **실기기 UX 미확인**. 칩 6개가 좁은 화면에서 어떻게 보이는지, 네 저장소를 한 번에 읽는 체감 속도 모두 코드상 판단(`추정`: 레코드가 요약 숫자뿐이라 4키 합쳐 수십 KB).
- `관례`: 세션 1건 수집이 흔함. 이 앱에서 A/B로 검증한 것은 아님.
