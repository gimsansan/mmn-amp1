# 앱 동작 파악 — 질문 요령

> **역할**: 파일을 열고 AI에게 물을 때, **함수부터 파지 않고** 동작을 빨리 그리는 법. **이 앱**(청능 웰니스·탭 화면) 기준.  
> **범용**(React 등): [`ask-file-behavior.md`](./ask-file-behavior.md)  
> **상태**: 2026-08-20 대화에서 맞춘 요령. 코드 동작의 정본은 아님.  
> **표기**: 화면 이름은 `[두 카드 선택]`처럼 대괄호. **동그라미 숫자(1, 2, 3 모양)로 화면을 매기지 말 것**(표시가 잘 안 보임).

관련: 탭 통계 표시는 [`training-stats-recommendation.md`](./training-stats-recommendation.md).

---

## 0. 한 줄

코드 조각을 붙여 「이 함수 하는 일」부터 물으면 느리다.  
**이 파일이 무슨 역할인지**를 먼저 고르게 하면, 다음 질문이 갈린다.

---

## 1. 첫 질문 (파일 종류를 모를 때) — 복붙

```
이 파일은 아래에 가까운가?
1. 화면을 갈아끼움
2. 기록을 넣거나 읽음
3. 숫자를 그림
4. 계산만

고른 뒤:
1이면 [화면] --동작--> [화면]
2이면 언제 1건이 저장되나. 안 넣는 경우는?
3이면 무슨 숫자 1개인지. 없는 값은 안 그리나?
4이면 입력→출력 한 줄.

동그라미 숫자로 화면 번호 매기지 마.
```

한 번에 「지도 그려」보다, **종류를 먼저** 받으면 된다.

---

## 2. 종류가 정해진 뒤

### 1) 화면을 갈아끼움 (`*TabScreen`, `PtaSessionScreen`, 세션을 감싼 탭)

파일 전체 **한 번**:

```
이 파일에서 사용자가 보는 화면이 어떻게 바뀌나.
[화면 이름] --동작--> [화면 이름] 만.
함수 이름은 화살표 옆에만.
동그라미 숫자 쓰지 마.
```

예 (`PtaSessionScreen`):

```
[두 카드 선택] --카드 누름--> [듣기 준비] --시작--> [연습]
[두 카드 선택] --차트--> [통계]
[듣기 준비] --뒤로--> [두 카드 선택]
[연습]       --뒤로--> [두 카드 선택]
[통계]       --돌아가기--> [두 카드 선택]
```

이 지도가 있으면 `openTrack` → 듣기 준비 → `passCheck` → 연습은 **한 장**에 나온다.  
같은 파일의 콜백을 하나씩 「하는 일」로 묻지 말 것.

이 앱에서 볼 자리: 위쪽 `useState`, 아래쪽 `if (...) return <어떤화면>`. **return이 갈라지는 곳**이 화면 기계다.

### 2) 기록 넣기/읽기 (`*Store.ts`)

```
언제 1건이 저장되나. 안 넣는 경우(미완료·귀풀기)는?
꺼낼 때 이 탭 kind만 거르나, 상자 전체를 펼치나?
```

### 3) 숫자를 그림 (진행 패널, `TrendChart`, 기록 화면 그래프)

```
무슨 숫자 1개를 그리나.
점 2개 미만이면? 가짜 점을 넣나, 선을 숨기나?
```

### 4) 계산만 (계단식, 세션 summarize, 보기 생성)

```
입력 → 출력 한 줄. 화면 이야기 하지 마.
```

---

## 3. 함수를 붙여 물을 때 (두 번째부터)

화면 파일의 **모든** 함수에 지도를 요청하지 말 것. 낭비다.

| 상황 | 질문 |
|------|------|
| 화면을 바꾸는 함수 (`backToPicker`, `openTrack`, `closeStats`) | 이 함수가 **바꾸는 화면만** `[이름] --동작-->` |
| 상태만인지 모름 (`passCheck`, 폰 뒤로) | 화면을 바꾸나, 상태만 바꾸나? 바꾸면 화살표, 아니면 「화면 이동 없음」 |
| 두 함수가 헷갈림 | `A` vs `B` 무엇이 다른가. 화살표 두 줄 |

코드 붙여 묻는 방식은 여기에 쓰면 된다. 파일 첫 질문은 파일만 지정해도 된다.

---

## 4. 하지 말 것

- 함수 본문의 `setState` 표부터 요청하기 (연결이 안 보임)
- 화면을 `①②③`으로 번호 매기기
- 「시각적으로 단계적 화면」만 말하고 이름 형식을 안 주기 → 동그라미 숫자가 나오기 쉬움
- 스토어·차트에 「화면 갈아끼움 지도」를 요청하기

「시각적으로… 이해하기 쉽겠어」는 **화면 파일에는 거의 충분**. 안 보이는 표시를 막으려면 `[화면 이름] --동작-->` 을 같이 적는다.

---

## 5. 이 앱 파일 감 (힌트)

| 경로 느낌 | 보통 |
|-----------|------|
| `src/app/` · `*TabScreen` · `PtaSessionScreen` | 1. 화면 갈아끼움 |
| `*Store.ts` | 2. 기록 |
| `*ProgressPanel` · `TrendChart` · `SessionTrendPanel` · `StatsScreen` | 3. 숫자 그리기 (+ 1이 섞일 수 있음) |
| `statsFeed.ts` | 2와 3 사이 — 저장소 4개를 읽어 `kind`로 넘겨주는 창구 |
| `*Session.ts` · `*Staircase.ts` · `wrsTrend.ts` | 4. 계산 |

감이 틀려도 §1 질문이 바로잡는다. 이름은 힌트일 뿐, 파일을 안 읽었으면 단정하지 말 것.
