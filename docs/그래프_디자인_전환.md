# 그래프·통계 화면 — 디자인만 전환

다른 앱에 **시각 규칙만** 옮길 때 쓰는 메모입니다.  
역치·세션·훈련 로직은 가져가지 않습니다.

기준 파일:

- `src/constants/theme.ts`
- `src/components/ThresholdChart.tsx`

## 가져갈 것 / 빼도 되는 것

| 가져갈 것 | 빼도 되는 것 |
|---|---|
| 라이트 화면 + 결론만 짙은 카드 | y축 뒤집기 (cent가 낮을수록 좋은 이 앱 전용) |
| 선 + 면적 그라데이션 + 마지막 점 강조 | Skia 구현, 세션 데이터, 역치 계산 |
| 큰 숫자 + 우상단 배지 + 축 라벨 + 하단 설명 | 훈련/평가 모드, 저장소 |
| 아래 흰 타일 3개 (테두리만, 그림자 없음) | `AUDIO` / `STAIRCASE` / `ASSESSMENT` 상수 |

## 화면 구성

```
[ 짙은 네이비 히어로 카드 — 이 화면의 결론 그래프 ]
[ 흰 타일 3개 — 보조 지표 ]
[ 요약 한 줄 ]
[ 최근 기록 리스트 — 흰 카드, 테두리만 ]
```

라이트 배경에서 **어두운 덩이는 그래프 카드 하나**만 둡니다. 시선이 그리로 모입니다.

## 간격·라운드·글자

- 간격: 4 / 8 / 12 / 16 / 20 / 24
- 라운드: 10 / 12 / 14 / 16 / 20 (히어로 카드는 20)
- 글자: 11 / 13 / 14 / 15 / 16 / 20 / 22
- 최근 값 숫자: 40, weight 800
- 터치 최소 높이: 48dp

그림자는 쓰지 않습니다. 면 구분은 테두리만. (`elevation`은 주 실행 버튼처럼 “지금 눌러야 할 것”에만)

## 히어로 차트 카드

파일: `src/components/ThresholdChart.tsx`

레이아웃 (위→아래):

1. 작은 eyebrow 라벨
2. 왼쪽: 최근 값 큰 숫자 + 단위 설명  
   오른쪽: 변화 배지 + `첫 측정 A → B`
3. 선그래프 (높이 96)
4. 축: 왼쪽 `가장 오래된` / 오른쪽 `최근`
5. 구분선 아래 한 줄 설명

그래프 시각:

- 선 두께 2.5, round cap/join, 색 `inkAccent`
- 선 아래 면적을 그라데이션으로 채움
- 중간 점: 반지름 3, `inkAccent`
- **마지막 점만** 반지름 5, 흰 원(`inkText`) + 오렌지 테두리 3px (`secondary`)

데이터 2개 미만: 큰 숫자(있으면) + 빈 안내 문구. 그래프는 그리지 않음.

배지:

- 개선: 초록 면 + `↓ n 개선`
- 악화: 투명 + 테두리 + `↑ n`
- 동일: `변화 없음`

y축: 이 앱은 “낮을수록 좋음”이라 뒤집혀 있습니다.  
다른 앱에서 값이 클수록 좋으면 **뒤집지 마세요.**

## 다른 곳에 붙일 때

1. 토큰(`theme`의 색·간격·라운드)을 먼저 맞춘다.
2. 화면의 **결론 지표 하나**만 짙은 카드로 올린다.
3. 차트는 선 + 면적 + 마지막 점 강조만 재현한다.
4. 아래는 흰 타일·리스트로 낮춘다.
5. 데이터 의미(역치, cent, y축 반전)는 새 앱 기준으로 다시 정한다.
