# 파일 동작 파악 — 질문 요령 (범용)

> **역할**: 파일을 열고 AI에게 물을 때, **함수부터 파지 않고** 동작을 빨리 그리는 법. React / React Native / 웹·앱 화면 코드에 공통.  
> **이 저장소 전용 예**: [`ask-app-behavior.md`](./ask-app-behavior.md)  
> **표기**: 화면·단계는 `[목록]` `[설정]`처럼 **이름**. 동그라미 숫자(1 2 3 모양)로 화면을 매기지 말 것(표시가 잘 안 보임).

코드 동작의 정본이 아님. 질문 형식만.

---

## 0. 한 줄

코드 조각을 붙여 「이 함수 하는 일」부터 물으면 느리다.  
**이 파일이 무슨 역할인지**를 먼저 고르게 하면, 다음 질문이 갈린다.

---

## 1. 첫 질문 (파일 종류를 모를 때) — 복붙

```
이 파일은 아래에 가까운가?
1. 화면·단계를 갈아끼움 (페이지, 모달, 마법사, 탭)
2. 데이터를 넣거나 읽음 (API, 저장소, 서버 상태)
3. 숫자를 그림 (차트, 대시보드, 진행률)
4. 계산만 (순수 함수, 포맷, 유효성)

고른 뒤:
1이면 [화면 이름] --동작--> [화면 이름]
2이면 언제 1건이 오가나. 안 보내는/안 넣는 경우는?
3이면 무슨 숫자 1개인지. 없는 값은 안 그리나?
4이면 입력 → 출력 한 줄.

동그라미 숫자로 화면 번호 매기지 마.
```

한 번에 「지도 그려」보다 **종류를 먼저**.

---

## 2. 종류가 정해진 뒤

### 1) 화면·단계를 갈아끼움

파일 전체 **한 번**:

```
이 파일에서 사용자가 보는 화면이 어떻게 바뀌나.
[화면 이름] --동작--> [화면 이름] 만.
함수 이름은 화살표 옆에만.
동그라미 숫자 쓰지 마.
```

React 예 (한 페이지 안 `step` / `view`):

```
[목록] --항목 누름--> [상세] --수정--> [편집]
[목록] --추가--> [작성]
[상세] --뒤로--> [목록]
[편집] --저장--> [상세]
[편집] --취소--> [상세]
```

라우터면 파일 하나가 한 화면일 수 있다. 그때는 **이 페이지에서 모달·패널이 어떻게 열리는지**만 그리면 된다. 라우트 이동은 `[이 페이지] --링크--> [다른 라우트]` 한 줄.

볼 자리: `if` / `switch(phase)` / 이른 `return <다른JSX>`. 그게 화면 기계다. `useState` setter 나열부터 묻지 말 것.

같은 파일의 onClick을 하나씩 「하는 일」로 묻지 말 것. 지도 한 장에 이어진다.

### 2) 데이터를 넣거나 읽음

```
언제 요청/저장이 나가나. 실패·빈 값·미완료는?
읽는 쪽이 필터하나, 받은 것 전부 보여 주나?
```

React 예: `useQuery` / `fetch` / Context / 로컬 스토리지 훅.

### 3) 숫자를 그림

```
무슨 숫자 1개를 그리나.
데이터가 부족하면? 가짜 점을 넣나, 차트만 숨기나?
```

### 4) 계산만

```
입력 → 출력 한 줄. 화면 이야기 하지 마.
```

---

## 3. 함수를 붙여 물을 때 (두 번째부터)

화면 파일의 **모든** 함수에 지도를 요청하지 말 것.

| 상황 | 질문 |
|------|------|
| 화면을 바꾸는 함수 | 이 함수가 **바꾸는 화면만** `[이름] --동작-->` |
| 상태만인지 모름 | 화면을 바꾸나, 상태만 바꾸나? 바꾸면 화살표, 아니면 「화면 이동 없음」 |
| 두 함수가 헷갈림 | `A` vs `B` 무엇이 다른가. 화살표 두 줄 |

코드 붙여 묻는 방식은 여기에. 파일 첫 질문은 파일만 지정해도 된다.

---

## 4. 하지 말 것

- 함수 본문의 `setState` / setter 표부터 요청하기
- 화면을 동그라미 숫자로 매기기
- 「시각적으로 단계적 화면」만 말하고 이름 형식을 안 주기
- 훅·유틸·차트에 「화면 갈아끼움 지도」를 요청하기

「시각적으로… 이해하기 쉽겠어」는 **화면 파일에는 거의 충분**. 안 보이는 표시를 막으려면 `[화면 이름] --동작-->` 을 같이 적는다.

---

## 5. 경로 감 (힌트, 단정 아님)

| 흔한 이름 | 보통 |
|-----------|------|
| `*Page` `*Screen` `*Tab` `*Layout` 라우트 파일 | 1. 화면 |
| `*api*` `*store*` `*service*` `use*Query` | 2. 데이터 |
| `*Chart*` `*Dashboard*` `*Stats*` | 3. 숫자 |
| `*util*` `*lib*` `*parser*` `*validate*` | 4. 계산 |

감이 틀려도 §1이 바로잡는다. 파일은 읽고 고른다.
