## 왜 `-s`가 필요한가

`adb`·`expo run:android` 같은 명령은 **연결된 기기가 1개일 때** 자동으로 그 기기를 씁니다. 지금처럼 2개가 잡혀 있으면:

```
error: more than one device/emulator
```

같은 오류가 나거나, **의도치 않은 쪽**(USB인지 WiFi인지)에 실행될 수 있습니다. 그래서 `-s <시리얼>`로 **대상을 명시**해야 합니다.

- USB 대상: `adb -s RF8MC0XZYLK ...`
- WiFi 대상: `adb -s 172.30.1.82:5555 ...`

여기서 `<시리얼>`은 `adb devices` 출력의 **첫 번째 칸 문자열** 그대로입니다.

## 지금 상태 정리

| 항목 | 값 | 의미 |
|------|----|------|
| `RF8MC0XZYLK` | USB 케이블 연결 | 뽑으면 사라짐 |
| `172.30.1.82:5555` | WiFi ADB | USB 뽑아도 유지(같은 공유기·앱 켜져 있을 때) |

이미 WiFi 전환은 끝난 상태라, **USB를 뽑아도 무선으로 계속 연결**됩니다.
