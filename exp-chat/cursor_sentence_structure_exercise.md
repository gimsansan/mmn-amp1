## ⓑ 오답 배치 (3-AFC)

**선택지 세트는 그리드의 행/열에서 나온다.** 음원 9개·이미지 9장으로 문항 18개(A형 9 + B형 9) 구성.

```
        전화받다  약먹다  우산쓰다
아버지     ①       ②      ③   ← A형 선택지 세트(행)
어머니     ④       ⑤      ⑥   ← A형
집배원     ⑦       ⑧      ⑨   ← A형
           ↑        ↑       ↑
        B형 선택지 세트(열)
```

**A형 (행동 변별): 주어 고정, 선택지 = 같은 주어의 3장**

| 문항 | 들려줄 문장(정답) | 선택지 3장 | 정답 |
|---|---|---|---|
| A1 | 아버지가 전화 받아요 | ① ② ③ | ① |
| A2 | 아버지가 약 먹어요 | ① ② ③ | ② |
| A3 | 아버지가 우산 써요 | ① ② ③ | ③ |
| A4 | 어머니가 전화 받아요 | ④ ⑤ ⑥ | ④ |
| A5 | 어머니가 약 먹어요 | ④ ⑤ ⑥ | ⑤ |
| A6 | 어머니가 우산 써요 | ④ ⑤ ⑥ | ⑥ |
| A7 | 집배원이 전화 받아요 | ⑦ ⑧ ⑨ | ⑦ |
| A8 | 집배원이 약 먹어요 | ⑦ ⑧ ⑨ | ⑧ |
| A9 | 집배원이 우산 써요 | ⑦ ⑧ ⑨ | ⑨ |

**B형 (주어 변별, 더 어려움): 행동 고정, 선택지 = 같은 행동의 3장**

| 문항 | 들려줄 문장(정답) | 선택지 3장 | 정답 |
|---|---|---|---|
| B1 | 아버지가 전화 받아요 | ① ④ ⑦ | ① |
| B2 | 어머니가 전화 받아요 | ① ④ ⑦ | ④ |
| B3 | 집배원이 전화 받아요 | ① ④ ⑦ | ⑦ |
| B4 | 아버지가 약 먹어요 | ② ⑤ ⑧ | ② |
| B5 | 어머니가 약 먹어요 | ② ⑤ ⑧ | ⑤ |
| B6 | 집배원이 약 먹어요 | ② ⑤ ⑧ | ⑧ |
| B7 | 아버지가 우산 써요 | ③ ⑥ ⑨ | ③ |
| B8 | 어머니가 우산 써요 | ③ ⑥ ⑨ | ⑥ |
| B9 | 집배원이 우산 써요 | ③ ⑥ ⑨ | ⑨ |

**요점**
- **음원 재사용:** 같은 문장 음원이 A형·B형 양쪽 정답으로 쓰인다(예: "아버지가 전화 받아요" = A1 + B1). 그래서 녹음 9개면 문항 18개.
- `Assumption:` B형이 A형보다 어렵다 — 선택지가 주어만 다르고 행동 그림은 동일해서 문장의 주어 단어를 정확히 들어야 한다. (검증 전 난이도 가정)
- 2-AFC로 낮추려면 각 선택지 세트에서 오답 1장 제거.

## 0. 한 줄 목표
성인·고령자용 **문장인지형 Closed 연습** 콘텐츠(평서문 듣고 맞는 그림 탭)를 만든다. 나(Claude)는 **문장(원본)** 을 쓰고, 사용자는 그에 맞는 **이미지**를 준비한다.

## 1. 절대 프레이밍 — 연습·웰니스 (측정 아님)
- **연습/웰니스**이지 **측정·진단·검사가 아니다.** 채점·총점(%)·발달단계 판정·"역치 확정" **금지.**
- 사용자에게 보여줄 건 **연습 기록 일지**뿐(무엇을 얼마나 연습했나, 격려 톤). 점수·판정 아님.
- **"실제 청취가 개선된다"는 전이 주장 금지**(카피·스토어에도 안 씀).
- 이 규율의 정본은 사용자 문서 `amp-mdt-training-design.md` §1·§4.1 (필요 시 사용자가 재업로드). 그 문서는 음악·심리음향(②주파수/①AM) 트랙용이고, **이 인계문은 같은 철학을 speech(말) 트랙 문장 콘텐츠에 적용**한 것이다.
- 라벨 규율(그 문서와 동일): `관례`/`가설`/`미검증`/`추정`/`주의`, 그리고 추론은 `Assumption:`.

## 2. 확정된 설계 결정 (이 대화에서)
1. **방식(Closed 매칭):** 녹음된 평서문 듣기 → 맞는 그림 탭 → 즉시 피드백(맞음/다시) → 다음. 모바일 적합, 기존 n-AFC(2택/3택) 상호작용과 같은 모델.
2. **문장인지형 선택.** 이유: 문장이해형(의문문·추론)보다 **난이도가 낮다**(들은 그대로 매칭). 참고로 KNISE 기준 문장인지=만3세+, 문장이해=만4세+(Hard 6세+).
3. **대상 = 성인·고령자, 유아 아님.** KNISE 원본 소재(곰·우유·아기 그림, 유아 어휘)는 **부적합** → **구조는 차용, 소재만 성인용으로 교체**:
   - 어휘·주제: 일상(전화·약·시장·버스·은행·날씨·가족 등).
   - 이미지: 담백하고 존중감 있는 일러스트/사진(만화풍 아기 그림 금지).
   - 톤: 유아 말투 금지.
   - 고령자 배려: 자극 간격·반응 대기 시간 넉넉히.
4. **IP:** KNISE-DASP 문장을 **그대로 쓰지 않는다.** 표현(문장)은 저작권 대상, **설계 원리(구조·난이도 방식)는 대상 아님** → 원리만 차용, 문장은 전부 새로 창작. (법률 자문 아님)
5. **트랙 정합:** 이건 speech 트랙(단어/문장 정확도) 콘텐츠. 순음·주파수 추론과 무관 → 3트랙 분리 원칙과 충돌 없음.

## 3. 차용할 설계 원리 3가지 — "연습" 목적으로 재해석
> KNISE의 원리는 가져오되, 목적은 "측정 타당도"가 아니라 **연습 품질·구성 유지·난이도 조절**이다.

1. **고정 정답세트 + 조합 구조** (예: 주어 N × 사물 M × 동사 K). 목적: 이미지 재사용·난이도 조절·연습 다양성. (진단 오답통제 아님)
2. **Easy/Hard가 같은 이미지 공유, 문장 복잡도만 스케일.** Easy=짧고 조사 축약("전화 받아") / Hard=조사 완비·정중형·수식 추가("어머니가 전화를 받으세요"). = 내부 난이도 조정.
3. **어휘·길이 통제(완화).** 성인 일상 어휘, 단문 위주, 낱말 수 적정 상한. 심리측정 비교성은 불필요(연습이므로).

**빼는 것(측정 장치):** 채점·총점·발달단계 판정·"25+ 문항 통계 신뢰도" 요건.

## 4. 녹음·이미지 제약 (문장 쓸 때 지킬 것)
- 문장은 사용자 녹음 프로토콜로 녹음 가능해야: WAV·모노·무가공(고주파 자음 보존). 자연스러운 평서문.
- 각 문장은 **그림 하나로 명확히 그릴 수 있어야** 한다(추상어·모호한 상황 회피).
- 정답세트 안에서 **오답 후보와 최소 차이**가 나게(예: 같은 주어, 사물만 다름) → 변별 연습이 되게.

## 데이터 초안 (생성형)

```ts
export const SUBJECTS = ["father", "mother", "postman"] as const;
export const ACTIONS = ["phone", "medicine", "umbrella"] as const;
export type SubjectId = (typeof SUBJECTS)[number];
export type ActionId = (typeof ACTIONS)[number];
export type SceneId = `${SubjectId}_${ActionId}`;

export type Scene = {
  id: SceneId;
  subject: SubjectId;
  action: ActionId;
  sentence: string; // 재생용. 보기 칸에 글자로 올리지 않음
  image: ImageSourcePropType;
  audio?: number;   // require(wav) — 녹음 후
};

export type TrialKind = "A" | "B"; // A=행동 변별(행), B=주어 변별(열)

export type ClosedSentTrial = {
  id: string; // "A1"…"A9", "B1"…"B9"
  kind: TrialKind;
  target: SceneId;
  choiceSet: readonly [SceneId, SceneId, SceneId];
};
```

A형은 `subject` 고정 → 그 행 3장. B형은 `action` 고정 → 그 열 3장. `father_phone` 음원 = A1 + B1.

표시 순서는 `choiceSet`과 분리하는 편이 낫다. 세트는 격자에서 고정, 칸 위치만 세션에서 섞기(위치 학습 방지). **미결정** — 아래.
